# 媒体库整理架构设计文档

## 一、文件夹分类（4 + 2 种）

### 核心规则：每个末端 = 一个刮削文件夹

| 类型 | 说明 | 刮削策略 | 前端展示 |
|------|------|----------|----------|
| movie | 单个电影，必须有独立文件夹 | 文件夹级 movie.nfo + poster | 直接显示详情 |
| tv | 剧集（含单季/多季） | tvshow.nfo + season.nfo + 分集 nfo | tab 切季 → 集列表 |
| series_collection | 系列电影聚合（如魔戒三部曲） | 不刮削聚合文件夹，各子文件夹独立刮削 | 缩略图列表，封面跟随选中项 |
| movie_collection | 电影聚合（如"欧美电影"） | 不刮削聚合文件夹，各子文件夹独立刮削 | 小卡片网格，封面固定 |
| variety | 综艺（文件名带日期） | 同 movie_collection | 同 movie_collection |
| misc | 杂项（CG/MV/短片） | 不刮削 | 同 movie_collection |

### 整理后的标准目录结构

```
NAS 根目录/
│
├── 欧美电影/                          ← movie_collection
│   ├── 盗梦空间 Inception (2010)/     ← movie（每个视频独立文件夹）
│   │   ├── *.mkv + movie.nfo + poster.jpg + *.srt
│   └── 星际穿越 Interstellar (2014)/
│
├── 魔戒三部曲/                        ← series_collection
│   ├── 指环王1 护戒使者 (2001)/       ← movie
│   ├── 指环王2 双塔奇兵 (2002)/
│   └── 指环王3 王者无敌 (2003)/
│
├── 黑镜 Black Mirror/                 ← tv
│   ├── tvshow.nfo + poster.jpg
│   ├── Season 01/
│   │   ├── season.nfo + poster.jpg
│   │   ├── S01E01.mkv + S01E01.nfo
│   │   └── S01E02.mkv + S01E02.nfo
│   └── Season 02/
│
├── 肖申克的救赎 (1994)/               ← movie
│   ├── *.mkv + movie.nfo + poster.jpg
```

## 二、分析层架构（analyzer.py）

### 职责：纯读取诊断，不修改文件

```
analyze_folder(path, library_data, tmdb_client) → {
    folder_type,           # 分类
    structure_ops,         # 结构调整计划（包文件夹/合并季/拆分季）
    rename_ops,            # 命名修正计划（清洗名 or NFO 标准名）
    scrape_issues,         # 刮削问题（缺 NFO/缺封面）
    shadow_name_issues,    # 影子名异常
    quality_issues,        # 质量问题（低清/低码率/旧编码）
    filename_issues,       # 文件名问题（广告/乱码/审查规避）
    subtitle_info,         # 字幕情况（外挂语种/缺中文）
    videos,                # 视频文件清单
}

analyze_library(base_path) → {
    results,               # 各文件夹分析结果
    cross_folder_issues,   # 跨文件夹问题（同剧多季散落）
    summary,               # 统计
}
```

### 关键能力

- CD 分片自动合并（阿甘正传CD1 + CD2 → 阿甘正传/）
- 广告/质量标签清洗（`_clean_filename_for_folder`）
- 审查规避检测（中英混杂异常，标记 needs_ai）
- 跨文件夹散落检测：文本核心名匹配 + TMDB ID 匹配（双轮）
- 每个 issue 带 severity（high/medium/low）+ auto_fixable 标记

## 三、一键整理执行链路

```
┌─────────────┐
│  1. 分析判断  │  analyzer.analyze_folder()
│  （纯读取）   │  → 产出 structure_ops / rename_ops / issues
└──────┬──────┘
       ↓
┌─────────────┐
│  2. 文件移动  │  organize_folder()
│  （结构归位）  │  消费 structure_ops 执行：
│              │  - 散装视频包进文件夹
│              │  - CD 分片合并
│              │  - 散落视频归入子目录
│              │  - 单子目录提升
└──────┬──────┘
       ↓
┌─────────────┐
│  3. 多季规整  │  reorganize_seasons()
│              │  - 混季拆分到子目录
│              │  - 同剧散落季合并
└──────┬──────┘
       ↓
┌─────────────┐
│  4. 刮削     │  scrape_folder() / scrape_video()
│              │  - 优先用清洗名搜 TMDB
│              │  - 写 tvshow.nfo / season.nfo / movie.nfo / 分集 nfo
│              │  - 下载 poster / fanart
└──────┬──────┘
       ↓
┌─────────────┐
│  5. 批量改名  │  rename_videos_in_folder()
│              │  - 读 NFO 数据生成标准名
│              │  - 格式：中文名 + 英文名 (年份)
│              │  - 关联文件（nfo/poster/字幕）同步改名
└─────────────┘
```

### 顺序设计理由

| 步骤 | 为什么在这个位置 |
|------|-----------------|
| 分析在最前 | 纯读取，不改文件，产出计划供后续消费 |
| 文件移动第二 | 结构归位后，后续操作在正确的文件夹里进行 |
| 多季规整第三 | 依赖稳定的文件夹结构，同季文件归到一起后共用刮削 |
| 刮削第四 | 结构完全确定后刮削，同季共用 NFO，减少请求 |
| 改名最后 | 依赖 NFO 数据（英文名/年份），刮削完才有完整数据 |

## 四、前端交互原型（4 种类型）

### movie — 直接显示详情

```
┌─────────────────────────────────┐
│  ┌───────┐                      │
│  │ 封面  │  标题 + 英文名 (年份) │
│  │       │  ★ 评分  |  时长     │
│  └───────┘                      │
│  剧情简介                       │
│  [搜索升级] [刮削] [重新匹配]   │
│  [移动] [复制] [删除] [移除]    │
│  [自动重命名] [一键整理]        │
└─────────────────────────────────┘
```

### tv — tab 切季 → 纯列表集

```
┌─────────────────────────────────┐
│  ┌───────┐                      │
│  │ 封面  │  剧名（封面跟随季）   │
│  │(跟随) │  ★ 评分  |  N季      │
│  └───────┘                      │
│  ┌S1┐┌S2┐┌S3┐┌S4┐  ← tab      │
│  ┌─────────────────────────┐    │
│  │ E01  标题        62min  │    │
│  │ E02  标题        58min  │    │
│  │ E03  标题        49min  │    │
│  └─────────────────────────┘    │
│  [搜索升级] [刮削] [重新匹配]   │
│  [一键整理]                     │
└─────────────────────────────────┘
```

### series_collection — 缩略图列表

```
┌─────────────────────────────────┐
│  ┌───────┐                      │
│  │ 封面  │  系列名（封面跟随）   │
│  │(跟随) │  N 部作品             │
│  └───────┘                      │
│  ┌─────────────────────────┐    │
│  │ 🖼 指环王1  2001  178m  │    │
│  │ 🖼 指环王2  2002  179m  │    │
│  │ 🖼 指环王3  2003  201m  │    │
│  └─────────────────────────┘    │
│  [搜索升级] [一键刮削]          │
│  [一键整理]  ← 无重新匹配      │
└─────────────────────────────────┘
```

### movie_collection — 小卡片网格

```
┌─────────────────────────────────┐
│  ┌───────┐                      │
│  │ 封面  │  聚合名（封面固定）   │
│  │(固定) │  N 部  |  总大小     │
│  └───────┘                      │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐   │
│  │ 🖼 │ │ 🖼 │ │ 🖼 │ │ 🖼 │   │
│  │盗梦│ │星际│ │信条│ │蝙蝠│   │
│  └────┘ └────┘ └────┘ └────┘   │
│  [搜索升级] [一键刮削]          │
│  [一键整理]  ← 无重新匹配      │
└─────────────────────────────────┘
```

### 交互差异对照

| 特性 | movie | tv | series_collection | movie_collection |
|------|-------|-----|-------------------|-----------------|
| 展开方式 | 无 | tab 切季→集列表 | 缩略图列表 | 小卡片网格 |
| 封面行为 | 固定 | 跟随当前季 | 跟随选中作品 | 固定（手动上传） |
| 重新匹配 | ✓ | ✓ | ✗ | ✗ |
| 刮削按钮 | 刮削 | 刮削 | 一键刮削 | 一键刮削 |
| 点击子项 | — | 切换到集详情 | 切换到作品详情 | 进入作品详情 |

## 五、刮削层级

```
tv 类型：
  tvshow.nfo    ← 剧级（标题/简介/评分/总季数）
  season.nfo    ← 季级（季封面/季简介/集数）  ← 待补充
  S01E01.nfo    ← 集级（分集标题/简介/剧照）

movie / series_collection 子项：
  movie.nfo     ← 电影级
  
movie_collection 子项：
  {filename}.nfo ← 视频级（同名风格）
```
