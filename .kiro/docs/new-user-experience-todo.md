## 核心问题

当前系统是为作者自用设计的，默认假设：
- 用户有 NAS + SMB 共享
- 媒体库有"电影"/"电视剧"等一级分类文件夹
- 用户懂 Prowlarr/qBittorrent/TMDB API Key
- 用户知道什么是 NFO/刮削/影子名

新用户面对的实际情况：
- 可能只有一个平铺的视频文件夹
- 不知道系统能做什么
- 不知道从哪里开始
- 看到空白页面不知道下一步
