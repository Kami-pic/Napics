## 核心问题

当前系统是为作者自用设计的，默认假设：
- 用户有 NAS + SMB 共享
- 媒体库有"电影"/"电视剧"等一级分类文件夹
- 用户懂 Prowlarr/qBittorrent/TMDB API Key
- 用户知道什么是 NFO/刮削/影子名

新用户面对的实际情况：
- 可能只有一个平铺的视频文件夹
- 不知道系统能做什么
- 不知道从哪里开始
- 看到空白页面不知道下一步

---

## 优化清单

### P0：首次启动引导（Setup Wizard）

- [ ] **检测首次启动**：`config.json` 不存在或 `nas_paths` 为空时触发
- [ ] **引导步骤 1 — 添加媒体目录**：
  - 大按钮"添加你的媒体文件夹"
  - 支持输入路径或浏览（如果本地运行）
  - 示例提示：`Z:\Movies`、`\\NAS\media`、`/volume1/video`
- [ ] **引导步骤 2 — 媒体库结构选择**：
  - 选项 A："我有分类文件夹"（电影/电视剧/动画等）→ 让用户标记每个一级文件夹的类型
  - 选项 B："我的文件都在一个文件夹里"→ 系统自动按文件特征分类（不依赖文件夹名）
  - 选项 C："我不确定"→ 先扫描，扫描后展示结构让用户确认
- [ ] **引导步骤 3 — 可选配置**：
  - TMDB API Key（提示获取方式 + 链接）
  - 代理配置（如果需要访问 TMDB）
  - 跳过按钮（"稍后配置"）
- [ ] **引导完成**：自动触发首次扫描，显示进度

### P0：媒体库结构灵活化

- [ ] **去除一级分类文件夹硬性假设**：
  - 扫描时如果路径下没有匹配 `category_tags` 的文件夹，不报错
  - 改为自动检测：有视频文件的文件夹自动归类（通过文件数量/NFO/文件名特征）
- [ ] **支持平铺结构**：
  - 单个文件夹下直接放电影文件（每个文件一部电影）
  - 单个文件夹下放多个剧集子文件夹（无一级分类）
- [ ] **手动分类入口**：
  - 扫描后未分类的文件夹，在 UI 中显示"未分类"标签
  - 用户可以右键/长按设置类型（movie/tv）
  - 批量分类：选中多个文件夹一键设为同一类型

### P1：空状态引导

- [ ] **首页空状态**：
  - 无媒体库时显示大图 + "开始使用" 引导卡片
  - 有媒体库但未扫描时显示"点击扫描开始整理你的媒体"
- [ ] **搜索空状态**：
  - 无搜索源时显示"前往插件中心安装搜索源"
  - 有搜索源但未配置时显示配置引导
- [ ] **发现页空状态**：
  - 无元数据源时显示"安装 TMDB 插件解锁影视推荐"
- [ ] **订阅空状态**：
  - 无 RSS 源时显示"安装订阅源插件开始追更"
- [ ] **下载管理空状态**：
  - 无下载器时显示"安装下载器插件管理下载任务"

### P1：术语与文案优化

- [ ] **避免专业术语直接暴露**：
  - "刮削" → "获取影视信息"或"匹配影视数据"
  - "NFO" → 在 UI 中不直接展示，内部概念
  - "影子名" → "英文别名"或"搜索用名"
  - "Provider" → "插件"或"服务"
  - "Action Plan" → "整理方案"
  - "dry-run" → "预览"
- [ ] **操作按钮文案清晰化**：
  - "重新匹配" → "重新识别"或"手动匹配影视信息"
  - "一键刮削" → "自动识别"
  - "整理" → "整理文件结构"
  - "归位" → "移动到正确位置"
- [ ] **状态提示人性化**：
  - "not_found" → "未能识别此影视"
  - "scrape_failed" → "获取信息失败，请检查网络或手动匹配"

### P1：设置页简化

- [ ] **分层设置**：
  - 基础设置（媒体库路径、语言、主题）始终可见
  - 高级设置（代理、排除目录、回收站）折叠
  - 插件设置（TMDB Key、Prowlarr 地址等）在对应插件安装后才出现
- [ ] **配置验证与反馈**：
  - TMDB API Key 输入后自动测试（绿色✓/红色✗）
  - Prowlarr 地址输入后自动测试连通性
  - 路径输入后自动检测是否可访问

### P2：操作引导与提示

- [ ] **首次扫描完成后**：
  - 弹出摘要："发现 X 部电影、Y 部剧集、Z 个未识别"
  - 引导下一步："点击未识别的文件夹手动匹配"或"安装 TMDB 插件自动识别"
- [ ] **功能发现提示**：
  - 首次进入文件夹详情时，轻提示"点击封面可以更换海报"
  - 首次看到质量评分时，轻提示"红色表示低质量，可以搜索更好的版本"
  - 首次看到完整性条时，轻提示"灰色表示缺失的集数"
- [ ] **错误恢复引导**：
  - 网络错误时提示"检查代理配置"而非只显示错误码
  - TMDB 限频时提示"请稍后重试"而非静默失败

### P2：多语言/国际化预留

- [ ] **UI 文案集中管理**：
  - 所有用户可见文案提取到 `i18n/zh-CN.json`
  - 当前只做中文，但结构预留多语言切换
- [ ] **日期/数字格式**：
  - 文件大小、日期显示跟随系统 locale

### P3：响应式与移动端适配

- [ ] **侧边栏折叠**：小屏幕自动折叠，汉堡菜单展开
- [ ] **卡片网格自适应**：根据屏幕宽度调整列数
- [ ] **触摸友好**：按钮最小 44px 触摸区域
- [ ] **PWA 基础**：manifest.json + service worker（离线缓存静态资源）
