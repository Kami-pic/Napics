# [TODO] 搜索匹配算法优化

> 目标：建立一套覆盖各种场景的搜索词构造 + 结果匹配 + 排序算法。
> 当前痛点：中文搜索容易没结果、不同源应该用不同的默认搜索词、排序缺乏匹配准确度维度。

## 1. 搜索词构造策略

### 1.1 多语言搜索词
- [ ] 每个媒体应有三个名称维度：中文名(cn)、英文名(en)、原名(original)
- [ ] 不同搜索源的默认搜索词不同：
  - Prowlarr：英文名优先（大部分索引器是英文站）
  - Bitsearch：英文名优先
  - 磁力熊/XL720：中文名优先（国产片源）
  - Nyaa：英文名/日文名优先（动画站）
  - 蜜柑：中文名/日文名优先（字幕组）
- [ ] 搜索词来源优先级：shadow_name > clean_name > 用户输入
- [ ] 季搜索词：中文"第N季" + 英文"S0N" 双路径

### 1.2 搜索词清洗
- [ ] 去掉年份后缀（部分站点搜索含年份会 0 结果）
- [ ] 去掉特殊字符（括号、冒号等）
- [ ] 中英文分离：从混合标题中提取纯中文和纯英文部分
- [ ] 别名扩展：从豆瓣/TMDB/Bangumi 获取别名列表

### 1.3 回退链
- [ ] 第一轮：精确搜索词（shadow_name 或 clean_name）
- [ ] 第二轮：中文名
- [ ] 第三轮：英文名
- [ ] 第四轮：原名
- [ ] 每轮有结果就停止，不继续搜

## 2. 结果匹配算法

### 2.1 匹配准确度评分
- [ ] 标题完全包含搜索词 → 高分
- [ ] 标题包含搜索词的中文部分 → 中高分
- [ ] 标题包含搜索词的英文部分 → 中分
- [ ] 标题和搜索词有部分重叠 → 低分
- [ ] 年份匹配加分
- [ ] 季号/集号匹配加分

### 2.2 过滤策略
- [ ] 后端不做过滤，返回全量结果给前端
- [ ] 前端三层分离：results(全量) → displayResults(智能过滤+排序) → filtered(筛选器+源开关)
- [ ] 智能过滤（🛡️按钮）：排除 TS/CAM/HDTC 等枪版资源，用户手动开启
- [ ] 磁力链接源（seeders=0 且 size=0）不受最低做种筛选影响
- [ ] 0 做种 0 大小的垃圾资源展示但排序滞后（不过滤，排到最后）
- [ ] 各源的标题相关性过滤在后端爬虫层做（XL720/磁力熊已实现中文子串过滤）
- [ ] Bitsearch/Nyaa 等英文站的结果需要在前端做标题匹配度排序（搜索词包含检查）

## 3. 排序算法

### 3.1 综合排序公式
- [ ] 匹配准确度（权重最高）
- [ ] quality_score（100 分制）
- [ ] seeders（做种数）
- [ ] size_gb（文件大小）
- [ ] 来源优先级（Prowlarr > 直搜源）

### 3.2 分组排序
- [ ] 同一来源内按 quality_score 排序
- [ ] 不同来源之间按匹配准确度交叉排列

## 技术要点
- 搜索词构造在前端（SearchModal 的 searchTags）和后端（alias_resolver）都有逻辑，需要统一

## 6. 2026-04-19 实测发现的问题

### 6.1 Prowlarr 索引器与爬虫源解耦（架构问题）
- [ ] Prowlarr 中的 mikan、nyaa 索引器和爬虫源（bt_scraper_mikan.py、bt_scraper_nyaa.py）没有解耦
- [ ] 如果 Prowlarr 里配了 mikan/nyaa 索引器，同时爬虫源也开着，会导致重复搜索
- [ ] 索引器列表不应该混入非 Prowlarr 的源（如 xl720、磁力熊）

### 6.2 FilterBar 筛选无效（需排查）
- [ ] 用户反馈"过滤按钮完全没有用，点击不会进行任何过滤"
- [ ] 可能原因：FilterBar 的 filters state 没有正确传递，或 applyFilters 的 isDefault 判断有问题
- [ ] 需要重启服务后复现确认

### 6.3 封面丢失（网络/代理问题）
- [ ] 关闭 clash 后，推荐卡片封面大部分丢失
- [ ] 详情页加载后却有封面（可能是缓存或不同的图片源）
- [ ] 需要检查封面 URL 是否走代理，以及 fallback 机制

### 6.4 非 TMDB 源缺少英文名（搜索准确性）
- [ ] 发现页中豆瓣/Bangumi 来源的条目没有英文名，导致 BT 搜索时只能用中文搜
- [ ] 媒体库已有英文名获取能力（shadow_name_manager.batch_generate），但发现页没有
- [ ] 需要在 normalizeItem 中补充英文名获取逻辑（从 TMDB API 查询）
