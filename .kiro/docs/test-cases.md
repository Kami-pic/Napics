# 整理功能测试用例集

## Day1 用例（来自 organize-operation-guide.md）

### 用例1：东京食尸鬼（多季剧集 + 广告文件名）
- 位置：`动画番\东京食尸鬼 Tokyo Ghoul`
- 期望类型：tv
- 验证点：
  - 季目录识别（"东京喰种第一季"含中文数字）
  - 广告检测（www.hltm.cc）
  - 清洗后不含广告
  - 刮削后有 tvshow.nfo + 每季 season.nfo

### 用例2：永远之久远（系列电影聚合 + 散装视频 + 独立NFO）
- 位置：`动画电影\永远之久远`
- 期望类型：series_collection
- 验证点：
  - 6个散装视频各自包进独立文件夹
  - 文件夹名由清洗函数生成（去广告去标签）
  - 关联文件跟随移入

### 用例3：经典电影（极端混合 + CD分片 + 多种广告）
- 位置：`电影\经典电影之新世代诠释 Reframed Next Gen Narratives`
- 期望类型：mixed
- 验证点：
  - CD分片合并（阿甘正传CD1+CD2、IF ONLY.CD1+CD2）
  - 广告清洗（www.dy2018.com, www.66Ys.Co, bbs.cnxp.com）
  - 清洗名测试：
    - `黑客帝国.1080p.BD中英双字无水印[66影视www.66Ys.Co].mkv` → `黑客帝国`
    - `星球大战前传1幽灵的威胁BD双语双字修复版[电影天堂www.dy2018.com].mkv` → `星球大战前传1幽灵的威胁`
    - `影视帝国(bbs.cnxp.com).触不到的恋人.cd1.rmvb` → `触不到的恋人`
    - `魔戒1加长版BD中英双字1280高清.rmvb` → `魔戒1`
    - `阿甘正传CD1.rmvb` → `阿甘正传`

### Day1 发现的错误和修正
1. `_is_season_dir` 不识别中文数字季号 → 加入 `第[一二三四五六七八九十]+季`
2. 永远之久远误判 tv → 独立 NFO 优先检查
3. collection 类型用了文件夹级 NFO 做 fallback → collection 不 fallback
4. 清洗函数广告清洗不彻底 → 重写清洗函数
5. Fate 天之杯被判 tv → 旧刮削打包策略
6. movie 类型被展开 → folder_type 检查
7. 前端崩溃 → 防御性检查 `|| []`
8. 聚合展开小卡片样式不一致 → 复用外层样式
